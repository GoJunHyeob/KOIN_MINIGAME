# 계속 이어지는 앞쪽 맵

이전에는 현재 행성과 바로 다음 목표만 준비해서 착륙마다 새 행성이 나타나는 느낌이었다. 이제 시작 시 현재 행성과 앞쪽 4개 행성을 준비한다. 4개 중 첫 행성만 금색 링의 실제 다음 목표이며 나머지도 이후에 그대로 도달할 수 있는 실제 행성이다.

## 진행과 생성

- 착륙하면 이미 보이던 다음 행성이 목표가 된다. 대기 중인 행성의 위치를 바꾸거나 교체하지 않는다.
- 화면 위쪽 너머의 맨 끝에 하나를 보충해 항상 앞쪽 4개를 유지한다. 기본 카메라/간격 설정에서는 새 행성이 현재 비행 화면 밖에 추가되고 스크롤을 통해 들어온다.
- 기존 카메라 크기·이동 방식·비행 중 화면 경계 고정·입력 대기·물리값을 유지한다.
- 위쪽 행성이 HUD 뒤로 지나가도 점수가 읽히도록 반투명 배경을 표시한다.
- 과거 행성은 화면 아래로 충분히 벗어난 경우에만 회수한다. 미래 행성은 회수 대상에서 제외한다.
- 기본 풀은 12개로 늘려 과거/현재/미래 행성에 여유를 둔다. 새 게임이나 진행에 따라 계속 늘어나지 않는다.

## 난이도와 도달 가능성

앞쪽 구간은 지금 점수가 아니라 그 구간을 출발할 예정 점수로 난이도를 계산한다. 예를 들어 현재 점수 3에서 대기 중인 4개 구간은 출발 점수 3, 4, 5, 6의 범위를 각각 사용한다. 따라서 초반 쉬운 구간과 30점 상한이 미리 생성해도 유지된다.

미래 행성의 도착 각도와 공전 방향은 아직 모르므로 실제 비행 적분을 이용해 양쪽 공전 방향에서 넉넉한 발사 창을 가진 후보만 사용한다. 실제 착륙 시에도 도착 각도로 다음 구간을 다시 확인하며, 이미 보이는 행성을 옮겨서 맞추지는 않는다. 모든 후보에 기존 거리·좌우 상한과 비겹침 검사를 적용한다.

Play 중 물리/난이도 설정을 바꿔도 이미 준비한 행성은 유지된다. 새 설정으로 전체 코스를 비교하려면 재시작한다. 잘못된 설정 때문에 도달 가능성을 만족할 수 없으면 기존 NO REACHABLE ROUTE 처리를 유지한다.

## Inspector

Endless Course > Relay Endless Course:

|항목|기본값|의미|
|---|---:|---|
|Planets Ahead|4|다음 목표를 포함해 미리 준비할 앞쪽 행성 수 (4~6)|
|Pool Size|12|과거·현재·미래를 포함한 전체 풀 크기 (12~16)|

기본 직교 크기 8, Camera Look Ahead 3.2에 맞춘 값이다. 카메라가 훨씬 넓거나 더 앞을 비추도록 바꿨다면 Planets Ahead를 늘려 화면 위쪽 생성 여유를 확보한다. Play 중 변경은 전체 맵을 즉시 재배치하지 않으므로 재시작 후 확인한다.

## 확인 방법

1. 시작부터 다음 목표 너머에 여러 실제 행성이 이어지는지 확인한다.
2. 착륙해도 앞서 보이던 행성의 좌표와 색이 유지되고, 금색 목표 링만 다음 행성으로 넘어가는지 확인한다.
3. 새 행성이 화면 한가운데 튀어나오지 않고 위쪽 스크롤로 들어오는지 확인한다.
4. 재시작하면 앞쪽 맵 전체가 같은 시드로 초기 배치에 돌아오는지 확인한다.


## 확인 결과 (2026-10-30)

Unity 6000.3.25f1에서 컴파일하고 씬에 Pool Size=12, Planets Ahead=4를 저장했다. 사용자가 다시 조정한 공전 150°/초와 나머지 물리값을 보존했다.

실제 이동 코드의 임시 복제본 검사에서 100회 연속 착륙, 앞쪽 4개 유지, 기존 미래 행성의 객체/좌표 고정, 화면 밖 꼬리 생성, 예정 점수별 난이도, 비행 카메라 잠금, 비겹침, 풀 유지(12개·활성 최대 8개), 전체 맵 재시작, 화면 이탈과 시간 초과를 통과했다. 실제 Play 화면에서 다음 목표 너머의 여러 행성과 점수 배경 가독성을 확인하고 Play를 종료했다. 실기기 빌드와 실측 성능 검증은 별도다.
