# 작은 행성·넓은 공전과 분산 배치 (2026-10-31)

행성은 작게, 공전 궤도는 크게 만들고 간격과 좌우 변화를 넓혔다. 발사 속도 15, 중력 60, 가속도 상한 40, 공전 속도 150, 포획 여유 0.30, 착륙 보정 0.06초는 유지한다.

|항목|이전|현재|
|---|---:|---:|
|행성 반경|0.8|0.5|
|Orbit Clearance|0.38|1.0|
|공전 반경 (반경+여유)|1.18|1.5|
|초반 높이 차|3.15~3.30|4.2~4.6|
|후반 높이 차|3.40~3.70|4.8~5.4|
|절대 좌우 위치|±1.6|±2.2|
|초반 최대 좌우 변화|0.45|2.6|
|후반 최대 좌우 변화|2.8|4.2|
|최소 좌우 변화|없음|1.2|

목표를 현재 x 근처에 붙여 뽑지 않고 최소 1.2 units의 좌우 차이를 요구한다. 대체 후보에도 같은 조건을 적용한다. 화면 안쪽 방향을 더 자주 선택하되 이동폭을 섞어 완전히 일정한 수직 줄이나 같은 폭의 지그재그가 되지 않도록 한다. 초반/중반/후반 보간과 30점 상한은 유지한다.

행성 표면·크레이터·공전 가이드와 씬의 초기 템플릿 배치도 함께 변경했다. 앞쪽 4개 선배치와 12개 풀은 유지한다. Play 중 설정을 변경했다면 재시작해야 전체 미래 맵에 반영된다.

## 자동 검사 코드 제거

- RelayPlayValidation.cs 및 .meta 삭제.
- RelayEndlessValidation.cs 및 .meta 삭제.
- RelaySceneBuilder의 BuildAndValidate, RunSmokeTests, Fly, Require와 테스트 메뉴 삭제.
- RelaySceneSetup의 자동 컴파일/설정 종료용 UpgradeAndExit 삭제.
- 문서의 삭제된 테스트 실행 방법 제거.

런타임 행성 생성에 필요한 겹침 방지/도달 가능한 후보 선택은 게임 기능으로 유지한다. 사용자 요청에 따라 이번 변경의 테스트, Play, 빌드/컴파일 검사 명령은 실행하지 않았다. 이전 문서의 통과 기록은 이전 버전에 대한 기록이며 이 배치의 결과가 아니다.
