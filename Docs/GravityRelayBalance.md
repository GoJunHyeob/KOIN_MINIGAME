# Gravity Relay: 빵 쏘고 탁 받는 기준값

2026-10-30, 고정 행성 3개 기준. 무한 진행 단계의 첫 물리 설정으로 사용한다. 실제 재미와 최종 난이도는 사용자 Play 피드백으로 확정한다.

## 의도와 적용값

느리게 떠다니는 비행 대신 빠른 접선 발사와 짧은 비행, 목표 근처에서 확실히 잡히는 착륙을 만든다. 속도만 높이면 목표를 스쳐 지나가므로 중력 상한과 포획 범위도 함께 조정한다.

디스크에 저장된 이전 씬은 속도 7 / 중력 22 / 공전 120 / 포획 여유 0.22 / 보정 0.15초였다. 작업 시작 시 열린 에디터의 미저장 비교값은 속도 20 / 중력 14 / 공전 120 / 포획 여유 0.1이었다. 코드 기본값만 바꿔도 기존 씬의 직렬화된 수치는 바뀌지 않는다. 이번 기준은 Inspector에 직접 적용한 뒤 씬에 저장한다. 직접 확장한 발사 범위 10~20은 유지한다.

|항목|적용값|기대 효과|
|---|---:|---|
|Launch Speed|15 units/s|기존 저장값 7보다 빠르게 발사. 시험값 20보다 조준 여유를 확보|
|Gravity Strength|60|빠른 속도에서도 목표 쪽으로 충분히 꺾임|
|Max Acceleration|40 units/s²|기존 12 상한 때문에 중력 증가가 막히지 않도록 조정|
|Softening|0.8|가까운 거리의 과도한 가속 완화 유지|
|Orbit Degrees Per Second|150°/s|한 바퀴 약 2.4초. 다음 발사까지의 대기 축소|
|Orbit Clearance|0.38|기존 공전 위치와 캐릭터 여유 유지|
|Capture Margin|0.30|빠른 발사를 받는 범위를 조금 넓힘|
|Capture Duration|0.06초|0.15초의 부드러운 붙음 대신 짧고 선명한 포획|
|Flight Time Limit|4초|기존 실패 규칙 유지|
|Screen Exit Margin|0.25|기존 화면 이탈 판정 유지|

행성 반경 0.8에서 공전 반경은 1.18, 포획 반경은 1.48이다. 행성 중심은 (-1,-3.2), (1,0), (-0.75,3.2)를 유지한다. 순서는 1→2→3→1.

## 순간 피드백

- 발사 후 0.10초 동안 캐릭터가 비행 방향으로 잠깐 늘어났다가 복원된다.
- 착륙 후 0.14초 동안 작은 크기 튕김과 기존 녹색 링/+1을 함께 표시한다.
- 이동 속도나 입력, 공전, 게임 시간은 연출 때문에 멈추지 않는다.
- Restart/비활성화 시 캐릭터 크기와 회전을 복원한다.

## Inspector 비교 프리셋

|이름|발사 속도|중력|포획 여유|공전 속도|
|---|---:|---:|---:|---:|
|쉬움|12|55|0.42|125|
|기본: 빵·탁|15|60|0.30|150|
|정밀|18|70|0.18|170|

모두 가속도 상한 40, 착륙 보정 0.06초를 적용한다. 이전 저속 프리셋은 사용자가 확장한 10~20 슬라이더 범위와 맞지 않아 함께 갱신했다.

## 직접 확인

GravityRelay 씬 Play → 기본 프리셋으로 연속 이동 → 빠른 발사와 짧은 착륙 확인 → 필요하면 쉬움 프리셋과 비교한다. 여전히 떠다니면 중력부터 올리기보다 비행 방향/착륙 시간을 함께 확인한다. 너무 자동으로 잡히면 포획 여유를 0.25까지 줄인다. 발사 타이밍이 바쁘면 공전 속도를 135까지 낮춘다. Play 중 수정은 종료 시 사라지므로 종료 후 재입력하고 씬을 저장한다.

## 확인 결과

열린 Unity 6000.3.25f1 에디터에서 새 스크립트/Inspector가 컴파일됐고, 기본 프리셋을 적용해 씬을 저장했다. 기존 Validate Movement 메뉴로 실제 Simulate 코드를 0.02초 간격으로 실행해 6회 연속 착륙(두 바퀴), Capturing 진입, 점수, 비행 시간 초과, 화면 이탈, 재시작 검사를 통과했다.

검사에서 각 구간의 첫 성공 타이밍으로 측정한 비행+착륙 시간은 1→2: 0.28/0.30초, 2→3: 0.28/0.30초, 3→1: 0.46/0.46초다. 발사 전 공전 대기 시간은 제외한다. 모든 발사 각도의 결과나 실제 입력 난이도를 보장하는 측정은 아니다. 스크린샷으로 씬의 15/60/40/0.30/150/0.06 설정 저장을 확인했다. 순간 늘어남/튕김의 실제 화면과 주관적인 손맛은 사용자 Play로 추가 확인한다.

## 무한 진행으로 넘길 조건

발사 속도 15와 반경/포획/중력 설정을 한 묶음으로 사용한다. 단순 거리만으로 도달 가능성을 보장하지 말고, 실제 고정 간격 이동 코드로 유효 발사 방향이 있는지 확인한다. 비행 중 화면 이탈 판정을 유지하고, 이번 고정 배치를 첫 생성 후보로 활용한다. 3→1 복귀는 현재 반복 검증용이며 무한 진행에서는 위쪽 목표로 치환한다.
