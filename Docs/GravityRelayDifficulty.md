# Gravity Relay 점진적 난이도

2026-10-31: 작은 행성·넓은 궤도 배치로 갱신했습니다. [GravityRelayLayout.md](GravityRelayLayout.md) 참고. 이번 변경은 테스트/Play 검사 없이 적용했습니다.

점수가 올라갈수록 행성 배치의 거리와 좌우 변화만 늘린다. 현재 목표의 위치나 비행 물리는 도중에 바꾸지 않는다. 설정은 착륙 후 다음 목표를 생성할 때 읽고, 재시작하면 점수 0의 쉬운 범위로 돌아간다.

앞쪽 맵 미리 생성에서는 각 구간을 출발할 예정 점수로 난이도를 계산한다. 이미 준비한 행성은 설정을 바꿔도 이동시키지 않으며, 새 설정은 맨 앞쪽에 보충되는 구간부터 적용한다. 전체 비교는 재시작 후 수행한다. 상세 내용은 [GravityRelayHorizon.md](GravityRelayHorizon.md) 참고.

## 기본 단계

|단계|점수|다음 목표 높이 차|현재 행성과 목표의 최대 x 차이|
|---|---:|---:|---:|
|초반|0~4|4.20~4.60|2.60|
|중반 예시|17|약 4.50~5.00|약 3.40|
|후반|30 이상|4.80~5.40|4.20|

5~29점에는 SmoothStep 곡선으로 연속 보간한다. 표의 중반은 대표값이며 별도 단계 전환이나 갑작스러운 증가가 없다. 각 목표의 실제 간격은 해당 점수의 범위 안에서 선택하므로 직전 구간보다 쉬운 구간이 섞일 수 있다. 30점 이후에는 더 증가하지 않는다.

모든 점수에서 목표의 절대 x 좌표는 -2.2~2.2으로 제한한다. 표의 x 차이는 현재 행성과 목표 사이의 차이이며 절대 좌표 범위와 다른 값이다. 첫 목표도 현재 행성에서 x 약 +1.6, 높이 약 +4.4의 쉬운 배치를 시도한다. 검사에 실패하면 같은 쉬운 범위의 다른 후보를 사용한다.

## Inspector

Endless Course > Relay Endless Course에서 다음을 조정한다. 컴포넌트 아래 미리보기에 초반/중반/후반의 실제 적용 범위가 표시되고, Play 중에는 현재 점수의 범위도 나온다.

|항목|기본값|역할|
|---|---:|---|
|Progressive Difficulty|켜짐|끄면 기존 고정 생성 범위를 사용|
|Easy Landings|4|이 점수까지 쉬운 범위 유지|
|Full Difficulty Score|30|이 점수에서 후반 범위 도달, 이후 유지|
|Early Min / Max Vertical Gap|4.20 / 4.60|초반 높이 차|
|Late Min Vertical Gap|4.80|후반 높이 차 하한|
|Early Horizontal Step|2.60|초반 좌우 변화 상한|
|Late Horizontal Step|4.20|후반 좌우 변화 상한|
|Min Vertical Gap|4.20|전 단계 높이 차 하한|
|Max Vertical Gap|5.40|전 단계 높이 차 상한, 후반 상한|
|Horizontal Limit|2.20|전 단계 절대 x 범위|

잘못된 단계값은 실행 시 전체 상한 안으로 제한하고, 종료 점수가 초반 점수보다 작으면 최소 한 점 이상의 증가 구간을 확보한다. 필드의 저장값을 자동 덮어쓰지는 않는다. Play 중 조정은 다음 생성부터 반영되며, 처음부터 비교하려면 재시작한다. 저장하려면 Play 종료 후 값을 입력하고 씬을 저장한다.

Minimum Horizontal Step=1.2를 모든 단계에 적용해 수직으로 붙는 배치를 줄입니다.

## 안전 조건

- 무작위 후보와 대체 후보 모두 같은 점수 범위·절대 좌우 상한을 지킨다.
- 기존 포획 반경 비겹침, 실제 비행 적분에 의한 연속 성공 타이밍 검사, 화면 경계·시간 제한을 유지한다.
- 현재 플레이어의 발사 속도·중력·가속도 상한·공전 속도·포획 여유·착륙 보정은 난이도가 변경하지 않는다.
- 작업 시작 시 사용자가 씬에서 조정한 공전 속도 100°/초를 보존한다. 발사 15, 중력 60, 가속도 상한 40, 포획 여유 0.30, 보정 0.06초도 유지한다.
- 사용자 설정으로 모든 후보가 불가능하면 불가능한 목표를 강제로 만들지 않고 기존 NO REACHABLE ROUTE 처리로 종료한다. 기본 범위를 먼저 사용한다.

## 확인 방법

1. Play에서 초기 목표들이 현재 행성에 가깝고 좌우 변화가 작게 나오는지 확인.
2. Inspector의 현재 범위를 보며 점수에 따라 서서히 늘고 30점부터 유지되는지 확인.
3. 다음 생성 전까지 기존 목표와 물리값이 바뀌지 않는지 확인.
4. R/실패 후 재시작해 쉬운 첫 배치로 복원되는지 확인.

## 확인 결과 (2026-10-30)

Unity 6000.3.25f1 컴파일 후 Inspector에서 초반/17점/30점 미리보기와 설정값을 확인하고, 점진적 난이도 활성 상태로 씬에 저장했다. 사용자 공전 속도 100°/초를 보존했다.

기본 시드 2718의 실제 이동 코드 검사에서 100회 연속 착륙, 매 목표의 점수별 높이·좌우 범위, 전체 상한, 쉬운 초반 유지, 30점 이후 범위 고정, 물리값 불변, 카메라 잠금, 비겹침, 풀 유지(8개·활성 최대 5개), 재시작, 화면 이탈, 시간 초과를 통과했다. 이번 검사는 임시 복제본의 고정 간격 시뮬레이션이며 실제 사용자 입력 난이도나 실기기 성능의 측정은 아니다.
