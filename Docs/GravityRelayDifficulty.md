# 연속 이동 기준값 (2026-10-31)

이번 기준은 좁은 타이밍을 기다리는 난이도에서, 착륙하고 다음 발사로 리듬을 이어가는 방향으로 변경했다. 기존 점수·최고 점수 방식은 유지하며 별도 콤보 배수나 자동 발사는 추가하지 않는다.

## 공전과 이동

- 행성 반경 0.5 유지, Orbit Clearance 1.0 → 1.3: 공전 반경 1.5 → 1.8(20% 확대). 가이드도 같은 반경을 사용한다.
- 발사 속도 15, 중력 60, 가속도 상한 40, 공전 150°/초, 기본 포획 여유 0.3, 착륙 보정 0.06초 유지.
- 초반 높이 차 5.6~5.9, 후반 6.1~6.6. 넓어진 공전·포획 반경이 겹치지 않도록 간격도 넓혔다. 절대 x 범위 ±2.2, 최소 좌우 변화 1.2, 초반 최대 변화 2.6, 후반 3.6.
- 직전 좌우 진행 방향을 85% 확률로 이어가는 후보를 우선하고, 가장자리에서는 안쪽으로 꺾는다. 연속 이동 벡터의 방향 변화는 최대 60°. 후반에도 갑작스러운 좌우 횡단보다 스윕·완만한 대각 배치를 조합한다. 범위·비겹침·양방향 성공 구간 조건을 통과한 후보만 생성한다.

## 다음 발사 연결

착륙 시 미리 배치된 다음 목표를 기준으로 양쪽 공전 방향의 첫 성공 구간까지 시간을 계산한다. 0.08초 이상 빠른 방향이 있으면 그 방향을 선택하고, 차이가 작으면 진입 방향을 유지한다. 착륙 위치를 다음 목표 쪽으로 순간이동시키거나 비행 중 조준·중력을 변경하지 않는다. Prefer Quick Departure를 끄면 기존 진입 운동 방향을 유지한다.

착륙 보정 중 또는 카메라가 아직 이동 중일 때 누른 발사는 Launch Buffer Seconds=0.35초 동안 보관한다. 발사 가능한 상태가 되면 한 번 실행하며 만료된 입력은 취소한다. 길게 누르기로 연사하지 않고 비행 중 입력도 저장하지 않는다. 카메라 Sharpness=28, Look Ahead=3.6으로 착륙 후 재구도를 빠르게 잡는다. 비행 중 카메라 고정·발사 당시 화면 경계 실패 판정은 유지한다. 모든 착륙에서 즉시 다음 발사가 성공한다는 보장은 없으며, 실제 도착 각도에 따라 기다렸다 발사해야 한다.

## 성공 구간 기반 난이도

|단계|성공 이동 횟수|최소 연속 성공 구간|
|---|---:|---:|
|튜토리얼|1|0.42초|
|초급|2~4|0.36초|
|보통|5~8|0.30초|
|어려움|9~15|0.26초|
|고급|16~25|0.24초|
|무한|26 이상|0.24초|

구간은 한 바퀴 안에서 연속으로 성공하는 발사 입력 시간이다. 콤보 제한 시간이나 비행 시간은 아니다. 첫 3회 쉬운 배치, 15점 이후 배치 수치 상한과 목표별 포획 보조(0.55/0.30/0.10/이후 0, 필요 시 최대 0.8)는 유지한다. 실제 비행 적분으로 생성 후보의 성공 구간을 샘플링하는 게임 로직은 유지하며, 이것은 테스트 도구가 아니다. 좁은 구간을 강제하지 않고 기준보다 넓은 구간도 허용한다.

## Inspector

Player > Relay Player: Orbit Clearance, Launch Buffer Seconds.

Endless Course > Relay Endless Course: Minimum Continuous Launch Window의 여섯 단계, Maximum Relay Turn, Direction Persistence, Prefer Quick Departure, Early/Late Vertical Gap 및 Horizontal Step, Camera Sharpness/Look Ahead. 값 변경 후 재시작하면 미리 생성된 맵에도 반영된다.

GravityRelay 씬에 값을 저장했으므로 별도 오브젝트 연결은 필요 없다. 실행 중 변경은 Play 종료 시 되돌아가므로 저장할 값은 종료 후 입력한다.

사용자 요청에 따라 테스트·Play·빌드·컴파일 검사를 실행하지 않았다. 위 값은 이번 플레이 조정을 위한 초기값이며 연속 발사 체감과 생성 성공률은 아직 측정하지 않았다.


2026-10-31 생성 실패 보정: 넓어진 간격에서 단계별 성공 구간·양방향 도달·포획 상한을 동시에 만족하지 못하면 생성이 실패할 수 있다. 기존 코드는 앞쪽 4개 중 먼 행성 하나만 실패해도 ResetCourse/Advance를 실패시켜 NO REACHABLE ROUTE → RUN OVER로 전환했다. 생성 후보가 없으면 결정적 좌우·높이 격자를 탐색하고 목표 성공 시간을 100%/75%/50%/Fallback Launch Window(기본 0.20초)까지 단계적으로 완화한다. 목표 행성에는 실제 채택한 시간을 저장한다. 표의 단계별 시간은 우선 목표이고, 대체 배치는 이 하한을 사용한다. 도달 가능성·포획 반경 비겹침·화면 경계·배치 상한은 우회하지 않는다. 당장 이동할 목표가 남아 있으면 먼 미리보기 생성 실패로 죽이지 않고 다음 착륙 때 다시 보충한다. 테스트·Play·컴파일 검사는 실행하지 않았으며 실제 재현 확인은 하지 않았다.
