# 성공 구간 기반 난이도 (2026-10-31)

공전 속도를 올리는 대신 행성 배치와 연속 발사 성공 구간으로 난이도를 조절한다. 현재 공전 150°/초, 발사 15, 중력 60, 가속도 상한 40을 난이도가 변경하지 않는다. 작은 행성 반경 0.5, 공전 반경 1.5, 앞쪽 4개 미리 생성과 12개 풀도 유지한다.

## 단계

|단계|다음 이동의 성공 횟수|최소 연속 발사 성공 구간|특징|
|---|---:|---:|---|
|튜토리얼|1회|0.40초|넓은 성공 구간과 목표 포획 보조|
|초급|2~4회|0.30초|쉬운 배치와 포획 보조|
|보통|5~8회|0.20초|좌우 위치 다양화|
|어려움|9~15회|0.15초|확대된 거리·좌우 범위|
|고급|16~25회|0.11초|배치 수치 상한 유지|
|무한|26회 이상|0.11초|상한 안에서 횡단·스윕·대각 패턴 조합|

현재 점수가 0이면 1번째 이동, 점수가 3이면 4번째 이동의 조건을 적용한다. 미래 행성도 해당 구간을 출발할 예정 점수로 조건을 저장한다. 이미 보이는 행성의 위치와 포획 보조를 난이도 변화 때문에 다시 바꾸지 않는다.

첫 3회는 쉬운 거리·좌우 범위를 유지한다. 이후 거리·좌우 변화는 15점(16번째 이동)까지 서서히 커지고 상한에서 유지된다. 성공 시간 표와 배치 보간은 별도 기준이다. 초반 높이 차 4.2~4.6, 후반 4.8~5.4, 절대 x=±2.2, 최소 좌우 변화 1.2를 유지한다.

## 성공 구간 계산

성공 구간은 비행 시간이 아니라, 한 바퀴 공전 중 연속으로 발사해도 같은 목표에 착륙할 수 있는 입력 시간이다. 생성 중 실제 게임의 중력·포획·비행 시간 제한·화면 경계 계산으로 발사 각도를 샘플링한다. 떨어진 성공 조각을 더하지 않으며, 360°/0° 경계를 잇는 연속 구간은 하나로 센다.

N개 성공 샘플은 N-1개 시간 간격으로 계산해 시간을 부풀리지 않는다. 미래 도착 방향이 미정이므로 양쪽 공전 방향에서 기준 시간과 한 고정 틱의 여유를 확보한다. 실제 도착 각도로도 다시 조건을 확인한다. 고정 간격 샘플링에 의한 추정이며 실제 터치 성공률을 측정한 값은 아니다. 초기 목표값은 사용자 Play로 보정한다.

## 목표별 포획 보조

위치만으로 초반 목표 시간을 확보하기 어려울 때를 위해 목표 행성에 추가 포획 여유를 저장한다. 기본 추가 여유는 튜토리얼 0.55, 초급 0.30, 보통 0.10, 이후 0이다. 후보에 필요한 경우 0.1씩 늘리되 최대 0.8까지만 허용한다. 실제 금색 링과 착륙 판정에 같은 여유를 사용하고, 비겹침 조건도 보조를 포함한 반경으로 적용한다.

보조는 목표 생성 때 정해지고 비행 중 바뀌지 않는다. 속도·중력·공전 속도를 갑자기 바꾸거나 발사 후 캐릭터를 자동 조준하지 않는다. 기준 이상으로 쉬운 구간도 허용하며, 후반 최소 시간이 반드시 정확히 0.11초 폭이라는 뜻은 아니다.
